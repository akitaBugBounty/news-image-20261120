# news-image-20261120

One image summing up the world news of Friday 20 November 2026:
"THE WORLD IN ONE DAY" — a 1024x1024 front page.

Stories: the Trump–Xi–Putin "peace declaration" from the first trilateral
summit in Shenzhen; the ICJ ruling that Myanmar committed genocide against
the Rohingya; the Houthi missile strike on Riyadh's PIF Tower; Anthropic's
record $81bn IPO (shares +17%) as the Dow drops 1,100. Ticker: Kyiv hit by
Russian missiles overnight, the COP31 draft drops fossil-fuel language,
Fiona the hippo dies.

## Run

`python3 main.py` writes `entry.png` (1024x1024, under 1 MiB) to
`$MAKEFUN_OUTPUT_DIR` (default `/output`). Stdlib only, no network.
The program copies the prepared image byte-for-byte, so repeated runs
produce identical output.
